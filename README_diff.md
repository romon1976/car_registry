# 🚗 Регистр автомобилей — Сиреневая 31

Веб-приложение для учёта автомобилей жильцов дома. Данные хранятся в Google Sheets и синхронизируются в реальном времени.

## ✨ Возможности

- 🔍 **Поиск** по номеру квартиры, гос. номеру, имени или телефону
- 📱 **Адаптивный дизайн** — удобно на компьютере и телефоне
- ➕ **Добавление** новых записей
- ✏️ **Редактирование** существующих записей
- 🗑️ **Удаление** неактуальных записей
- 📊 **Сортировка** по квартире, имени, дате
- 🔄 **Синхронизация** с Google Sheets в реальном времени
- 📞 **Быстрый звонок** — нажатие на номер телефона

## 🚀 Быстрый старт

### 1. Клонирование и установка

```bash
git clone https://github.com/ВАШ_USERNAME/car-registry.git
cd car-registry
npm install
```

### 2. Настройка Google Sheets API

#### Шаг 1: Подготовьте Google таблицу

Откройте вашу Google таблицу (или создайте новую). Структура должна быть:

| Квартира | Телефон 1 | Телефон 2 | Г/Н автомобиля | Имя | Дата обновления |
|----------|-----------|-----------|----------------|-----|-----------------|
| 3        | 89951530932 |         | О 569 КС 716   | Олеся | 10.10.23       |
| 42       | 89139802442 |         | А 142 НН 154   | Роман | 25.05.25       |

> ⚠️ **Важно:** Первая строка должна содержать заголовки: `Квартира`, `Телефон 1`, `Телефон 2`, `Г/Н автомобиля`, `Имя`, `Дата обновления`

#### Шаг 2: Создайте Apps Script

1. Откройте вашу Google таблицу
2. В меню выберите **Расширения → Apps Script**
3. Удалите весь существующий код в редакторе
4. Скопируйте и вставьте код из файла `google-apps-script.js` (в корне этого проекта)
5. Нажмите 💾 **Сохранить** (или Ctrl+S)
6. Дайте проекту имя, например "Car Registry API"

#### Шаг 3: Разверните веб-приложение

1. В Apps Script нажмите кнопку **Deploy** (синяя кнопка справа вверху)
2. Выберите **New deployment**
3. Нажмите на ⚙️ шестерёнку рядом с "Select type"
4. Выберите тип **Web app**
5. Заполните настройки:
   - **Description:** `Car Registry API`
   - **Execute as:** `Me (ваш email)`
   - **Who has access:** `Anyone`
6. Нажмите **Deploy**
7. Google попросит авторизацию — разрешите доступ
8. **Скопируйте URL** веб-приложения (выглядит как `https://script.google.com/macros/s/AKfycbx.../exec`)

#### Шаг 4: Подключите URL к проекту

1. В корне проекта создайте файл `.env`:

```
VITE_GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/ВАШ_ID/exec
```

2. Замените `ВАШ_ID` на ваш реальный URL из шага 3

#### Шаг 5: Сборка и деплой

```bash
npm run build
```

Результат будет в папке `dist/`. Загрузите его на GitHub Pages или любой хостинг.

### 3. Деплой на GitHub Pages

```bash
# Установите gh-pages
npm install -D gh-pages

# Добавьте в package.json скрипт:
# "deploy": "npm run build && gh-pages -d dist"

# Задеплойте
npm run deploy
```

В настройках репозитория на GitHub:
- **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: **gh-pages** / **root**

## 🔧 Режимы работы

### С подключением к Google Sheets
Все изменения (добавление, редактирование, удаление) синхронизируются с таблицей в реальном времени. Все пользователи видят актуальные данные.

### Без подключения (fallback)
Если API не настроен, приложение работает с начальными данными. Изменения сохраняются только в рамках текущей сессии браузера.

## 🔒 Безопасность

- Google Apps Script выполняется от имени владельца таблицы
- Доступ к таблице имеют только те, кому вы дали разрешение
- Веб-приложение доступно всем, но может только читать/писать через API
- Для ограничения доступа можно изменить "Who has access" на "Anyone with the link"
